
### **P0 - 当前必须实现**

| 功能编号      | 功能名称     | 功能描述                                                                             |
| --------- | -------- | -------------------------------------------------------------------------------- |
| F-MAP-001 | 单目标路径规划  | 从起点到终点的最短路径计算                                                                    |
| F-MAP-002 | 最短距离策略   | 以距离为边权的 Dijkstra 算法                                                              |
| F-MAP-003 | 路径结果数据输出 | 为前端地图展示提供路径数据                                                                    |
| F-MAP-005 | 基础异常处理   | 不可达/节点不存在等场景                                                                     |
| F-MAP-015 | 输入地点查询   | 用户可以输入景点和学校的名称、类别、关键字等进行查询                                                       |
| F-MAP-016 | 地图选点查询   | 选中某个景点或者场所后，找出附近一定范围内的超市、卫生间等设施，并根据距离进行排序<br>选中游览景点和学校后，可以按照用户选择的热度、评价和距离对美食进行排序 |

问题：001和002的区别是什么
回答：F-MAP-001 是上层业务功能，可以调用 F-MAP-002（最短距离）或 F-MAP-006（最短时间）等不同策略来实现路径计算
