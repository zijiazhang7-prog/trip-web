
# 地图模块 API 接口定义

## 1. 模块概述

### 1.1 功能范围

地图模块提供以下能力：

| 功能编号 | 功能名称 | 优先级 | 说明 |
|----------|----------|--------|------|
| F-MAP-001 | 单目标路径规划 | P0 | 计算从起点到终点的最优路径 |
| F-MAP-002 | 最短距离策略 | P0 | 以距离为权重的路径规划 |
| F-MAP-003 | 路径结果数据输出 | P0 | 返回路径坐标、距离、耗时等 |
| F-MAP-005 | 基础异常处理 | P0 | 参数校验、不可达等错误处理 |
| F-MAP-015 | 输入地点查询 | P0 | POI 搜索与输入提示 |
| F-MAP-016 | 地图选点查询 | P0 | 周边设施搜索 |

### 1.2 技术说明

- **数据源**: 高德地图 Web 服务 API（后端代理）
- **坐标系**: GCJ-02（火星坐标系）
- **安全**: API Key 由后端持有，前端通过本系统接口访问

### 1.3 与其他模块的关系

- **Route 模块**: 目的地内部路径规划使用 `map_node` 和 `map_edge` 表
- **Facility 模块**: 周边设施查询可复用本模块的地理位置计算能力
- **Diary 模块**: 日记中的位置信息可通过地理编码接口转换

## 2. 接口列表

| 接口 | 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|------|
| 单目标路径规划 | POST | `/api/v1/routes/plan/single` | 否 | 计算两点之间的最优路径 |
| POI 关键词搜索 | GET | `/api/v1/pois/search` | 否 | 根据关键词搜索地点 |
| POI 输入提示 | GET | `/api/v1/pois/tips` | 否 | 搜索联想建议 |
| 周边设施搜索 | GET | `/api/v1/pois/nearby` | 否 | 查找指定地点周边的设施 |
| 地址转坐标 | GET | `/api/v1/geocode` | 否 | 地理编码 |
| 坐标转地址 | GET | `/api/v1/reverse-geocode` | 否 | 逆地理编码 |

## 3. 核心数据对象

### 3.1 LocationVO（位置坐标）

```json
{
  "lng": 116.481488,
  "lat": 39.990475
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `lng` | number | 经度（GCJ-02 坐标系） |
| `lat` | number | 纬度（GCJ-02 坐标系） |

### 3.2 LocationWithNameVO（带名称的位置）

```json
{
  "lng": 116.481488,
  "lat": 39.990475,
  "name": "可选名称"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `lng` | number | 是 | 经度 |
| `lat` | number | 是 | 纬度 |
| `name` | string | 否 | 位置名称（用于展示） |

### 3.3 POIVO（兴趣点）

```json
{
  "poiId": "B000A7BK6G",
  "name": "故宫博物院",
  "type": "110000",
  "typeName": "风景名胜",
  "location": {
    "lng": 116.397428,
    "lat": 39.916345
  },
  "address": "北京市东城区景山前街 4 号",
  "city": "北京市",
  "distance": null,
  "rating": 4.8,
  "bizExt": {
    "openingHours": "08:30-17:00",
    "telephone": "010-85007421"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `poiId` | string | 高德 POI ID |
| `name` | string | 名称 |
| `type` | string | POI 类型代码 |
| `typeName` | string | POI 类型名称 |
| `location` | LocationVO | 坐标 |
| `address` | string | 地址 |
| `city` | string | 城市 |
| `distance` | integer | 距离（米），仅 around 搜索时有值 |
| `rating` | decimal | 评分 |
| `bizExt` | object | 扩展信息（营业时间、电话等） |

### 3.4 RoutePlanMapVO（地图路径规划结果）

```json
{
  "origin": {
    "lng": 116.481488,
    "lat": 39.990475,
    "name": "起点名称"
  },
  "destination": {
    "lng": 116.406692,
    "lat": 39.907812,
    "name": "终点名称"
  },
  "strategy": "shortest_distance",
  "distance": 12580,
  "duration": 2340,
  "path": {
    "type": "LineString",
    "coordinates": [
      [116.481488, 39.990475],
      [116.478123, 39.988234],
      [116.406692, 39.907812]
    ]
  },
  "steps": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `origin` | LocationWithNameVO | 起点 |
| `destination` | LocationWithNameVO | 终点 |
| `strategy` | string | 策略：`shortest_distance` / `shortest_time` |
| `distance` | integer | 总距离（米） |
| `duration` | integer | 总耗时（秒） |
| `path` | GeoJSON LineString | 路径坐标串 |
| `steps` | array | 详细步骤（当 extensions=all 时返回） |

## 4. 路径规划接口

### 4.1 单目标路径规划

**接口**: `POST /api/v1/routes/plan/single`

**描述**: 计算从起点到终点的最优路径（支持距离/时间策略）

**请求体**:

```json
{
  "origin": {
    "lng": 116.481488,
    "lat": 39.990475,
    "name": "可选起点名称"
  },
  "destination": {
    "lng": 116.406692,
    "lat": 39.907812,
    "name": "可选终点名称"
  },
  "strategy": "shortest_distance"
}
```

**参数说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `origin.lng` | number | 是 | 起点经度（GCJ-02） |
| `origin.lat` | number | 是 | 起点纬度（GCJ-02） |
| `origin.name` | string | 否 | 起点名称 |
| `destination.lng` | number | 是 | 终点经度（GCJ-02） |
| `destination.lat` | number | 是 | 终点纬度（GCJ-02） |
| `destination.name` | string | 否 | 终点名称 |
| `strategy` | string | 否 | 策略：`shortest_distance`（默认） / `shortest_time` |

**成功响应**:

```json
{
  "success": true,
  "code": "SUCCESS",
  "message": "success",
  "data": {
    "origin": {
      "lng": 116.481488,
      "lat": 39.990475,
      "name": "起点名称"
    },
    "destination": {
      "lng": 116.406692,
      "lat": 39.907812,
      "name": "终点名称"
    },
    "strategy": "shortest_distance",
    "distance": 12580,
    "duration": 2340,
    "path": {
      "type": "LineString",
      "coordinates": [
        [116.481488, 39.990475],
        [116.478123, 39.988234],
        [116.406692, 39.907812]
      ]
    },
    "steps": []
  },
  "timestamp": "2026-04-29T12:00:00"
}
```

**错误响应示例**:

```json
{
  "success": false,
  "code": "MAP_003",
  "message": "起点与终点之间无可行路径",
  "data": null,
  "timestamp": "2026-04-29T12:00:00"
}
```

**可能的错误码**:

| 错误码 | HTTP 状态码 | 说明 |
|--------|-------------|------|
| `COMMON_001` | 400 | 请求参数缺失或格式错误 |
| `MAP_001` | 400 | 缺少起点坐标 |
| `MAP_002` | 400 | 缺少终点坐标 |
| `MAP_003` | 400 | 坐标格式错误或超出范围 |
| `MAP_006` | 400 | 不支持的路径规划策略 |
| `MAP_200` | 404 | 起点终点之间无可行路径 |
| `MAP_502` | 500 | 外部地图服务调用超时 |
| `MAP_999` | 500 | 系统内部未知错误 |

## 5. POI 查询接口

### 5.1 POI 关键词搜索

**接口**: `GET /api/v1/pois/search`

**描述**: 根据关键词搜索地点（景点、学校、美食等）

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keywords` | string | 是 | 搜索关键词（1-50 字符） |
| `types` | string | 否 | POI 类型代码（如：110000=旅游景点） |
| `city` | string | 否 | 城市名称或编码 |
| `pageNum` | integer | 否 | 页码，默认 1 |
| `pageSize` | integer | 否 | 每页数量，默认 20，最大 50 |

**成功响应**:

```json
{

  "code": "SUCCESS",
  "message": "success",
  "data": {
    "list": [
      {

        "name": "故宫博物院",
        "type": "110000",
        "typeName": "风景名胜",
        "location": {
          "lng": 116.397428,
          "lat": 39.916345
        },
        "address": "北京市东城区景山前街 4 号",
        "city": "北京市",
        "distance": null,

    "pageNum": 1,
    "pageSize": 20,
    "total": 156,
    "pages": 8
  },
  "timestamp": "2026-04-29T12:00:00"
}
```

**可能的错误码**:

| 错误码 | HTTP 状态码 | 说明 |
|--------|-------------|------|
| `COMMON_001` | 400 | 请求参数缺失或格式错误 |
| `MAP_005` | 400 | 搜索关键词为空或过长 |
| `MAP_008` | 400 | 分页参数不合法 |
| `MAP_201` | 404 | 未找到匹配的地点 |
| `MAP_502` | 500 | 外部地图服务调用超时 |

## 8. 注意事项

### 8.1 坐标系说明

- 高德地图使用 **GCJ-02** 坐标系（火星坐标系）
- 如需使用 WGS-84 或 BD-09，需自行转换
- 不同坐标系混用会导致位置偏移

### 8.2 限流说明

- 路径规划：10 次/分钟/用户
- POI 搜索：30 次/分钟/用户
- 输入提示：60 次/分钟/用户

### 8.3 缓存策略

- POI 搜索结果缓存 24 小时
- 相同起终点路径缓存 1 小时
- 高频关键词提示缓存 12 小时
