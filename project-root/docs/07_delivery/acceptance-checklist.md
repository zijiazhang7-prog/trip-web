### 6.3 算法说明

- 数据结构：有向带权图邻接表、优先队列、距离表、前驱表。
- 最短距离边权：`distance`。
- 最短时间边权：`distance / (ideal_speed * crowd_factor)`。
- Dijkstra 时间复杂度：`O((V+E) log V)`。
- 多目标启发式复杂度：目标数为 `k` 时约 `O(k(V+E) log V)`。
- 适用范围：非负边权、目的地内部中小规模道路图。
